# JarnTo Portfolio

Portfolio ເວັບສ່ວນຕົວແບບ Static Website — ບໍ່ຕ້ອງມີ Backend.

## ຟີເຈີ
- 🌙 Dark Mode / ☀️ Light Mode
- 🇱🇦 ພາສາລາວ / 🇬🇧 English
- 📱 Responsive ສຳລັບ PC, Tablet ແລະ Mobile
- 🗂️ Portfolio ແຍກໝວດ: Web, System, Gaming, Design, Video
- 🔎 Filter ຜົນງານ
- 🖼️ Gallery + Fullscreen Modal
- 🎬 Video section ສຳລັບ MP4
- ✨ Scroll animation
- 💾 ຈື່ຈຳ Theme ແລະ Language ດ້ວຍ localStorage
- 📂 ສາມາດໃສ່ຮູບ/ວິດີໂອຈິງຂອງຕົນເອງ

## ເປີດໃຊ້
1. Extract ZIP.
2. ເປີດໂຟນເດີໃນ VS Code.
3. ເປີດ `index.html` ດ້ວຍ Browser ຫຼື Live Server.

## ໃສ່ຮູບ Profile
ເອົາຮູບຂອງຂ້ອຍໃສ່:
`images/profile/profile.jpg`

## ໃສ່ຮູບຜົນງານ
ແນະນຳ:
`images/projects/`
`images/gallery/`

ແລ້ວໄປແກ້ `js/projects.js` ໃນຕົວແປ `PROJECTS` ແລະ `GALLERY`.

## ໃສ່ວິດີໂອ
ວາງ `.mp4` ໃນ:
`videos/`

ແລ້ວແກ້ `src` ໃນ `VIDEOS` ຕົວຢ່າງ:
`src:"videos/my-video.mp4"`

## ແກ້ຂໍ້ມູນຕິດຕໍ່
ແກ້ໃນ `index.html` ບ່ອນ Contact:
- Email
- Facebook
- YouTube
- TikTok
- GitHub

## ແກ້ຂໍ້ຄວາມ / ສອງພາສາ
ຂໍ້ຄວາມ UI ຢູ່ `js/main.js` ພາຍໃນ `I18N`.
ມີ `lo` ສຳລັບລາວ ແລະ `en` ສຳລັບ English.
